Cette page documente l’échelle typographique et les règles utilisées.

## Police

- Base: Poppins (importée dans `documentation/src/css/custom.css`)
- Poids utilisés: 400, 600, 700

## Titres (docs)

```text
h1: ~2.15rem (700)
h2: ~1.6rem  (700)
h3: ~1.25rem (600)
```

Ajustements au scroll (anchors `#`) visibles au survol.

## Sidebar (docs)

- Catégories plus visibles (gras), liens de page plus compacts.
- Sidebar compacte: largeur ~180px, taille réduite pour améliorer le signal.

## Inline code

- Fond léger doré, lisible en dark mode.

## Bonnes pratiques

- Ne pas multiplier les tailles non nécessaires.
- Conserver l’échelle pour la cohérence visuelle.
- Vérifier la lisibilité (contraste, interlignage).
