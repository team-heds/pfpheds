# HEDS25-625 — Console administrative de gamification

## Objectif

Donner aux administrateurs une vue fiable, lisible et strictement en lecture seule de l’état de la gamification sur l’environnement de test.

## Périmètre livré

- règles XP actives, montants et plafonds ;
- volumes de quêtes, défis et badges selon leur état ;
- activité agrégée sur 30 jours, hors soldes d’ouverture importés ;
- contrôles de qualité et avertissements existants ;
- raccourcis vers les écrans de gestion ;
- date de fraîcheur, source et définitions visibles ;
- aucune donnée personnelle et aucune correction manuelle d’XP.

## Évolution livrée avec HEDS25-626

Les événements refusés par le moteur sont maintenant journalisés dans un espace
privé et présentés uniquement sous forme d'agrégats sans donnée personnelle.
La console n'affiche plus « non mesurés » lorsque la mesure est disponible.

## Preuves attendues

- test SQL d’isolation admin/étudiant et absence d’écriture ;
- tests unitaires du contrat frontend ;
- build de test isolé ;
- parcours navigateur admin et contrôle responsive ;
- production inchangée.
