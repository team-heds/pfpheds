# HEDS25-617 — Jeu de test gamification reproductible

Recherche : `docs/research/HEDS25-617.md`.

## Périmètre proposé

Construire sur `test.hedsvs.ch` une infrastructure de pilote isolée et
réinitialisable pour un compte administrateur fictif et un compte étudiant
fictif. Cette livraison couvre les scénarios déjà supportés par le moteur
(connexion, profil, publication, défi, badge et rejeu). Quête complète,
expiration et plafond restent signalés comme non exécutables jusqu'aux tickets
moteur correspondants ; aucune simulation trompeuse ne les marquera réussis.

## Plan ordonné

### 1. Encadrer les lots pilote dans Supabase

- [x] Ajouter une migration append-only avec un registre et un audit dans
  `gamification_private`, plus les références explicites aux comptes et objets
  créés par chaque lot.
- Fichiers attendus : nouvelle migration `supabase/migrations/*`, test SQL
  `supabase/tests/gamification_pilot_isolation.sql`.
- Autorisé : schéma de test et fonctions génériques promotionnables après
  revue. Interdit : identifiants personnels, secrets, suppression globale et
  modification de production.
- Sécurité : RLS, aucun accès direct `anon`/`authenticated`, fonctions admin
  avec `search_path` fixé et `app_is_privileged()`.
- Validation : migration + tests dans une transaction annulée via Portly.
- Retour arrière : désactiver le lot ; conserver l'audit et les données hors
  lot.

### 2. Ajouter aperçu, installation et remise à zéro idempotents

  installation d'un lot versionné et remise à zéro limitée aux objets inscrits
  dans ce lot.
- La remise à zéro doit reconstruire journal XP, solde, niveau et contribution
  de maison de l'étudiant pilote sans toucher à un autre utilisateur.
- Interdit : `truncate`, filtre par domaine email, plage de dates non bornée ou
  suppression d'un contenu non enregistré dans le lot.
- Tests : deuxième installation et deuxième reset sans effet ; données témoin
  hors lot inchangées ; refus étudiant et anonyme.
- Validation : comparer les résumés avant/après, sans donnée personnelle.
