# HEDS25-638 — Harmoniser le design des tableaux et dashboards SI

## Objectif

Donner aux six écrans d'administration Soins infirmiers une hiérarchie et une densité cohérentes, sans modifier leurs règles métier ni leurs permissions.

## Périmètre

- Dashboard Secrétariat SI
- Dashboard RM SI
- Dashboard Enseignant SI
- Vue journalière et salles
- Feuille de charges
- Cours en postulation

## Décisions

- conserver la charte sombre HES-SO et l'accent jaune existants ;
- ajouter un socle CSS strictement limité aux écrans SI ;
- harmoniser en-têtes, cartes statistiques, barres de filtres, sections et tableaux ;
- afficher enfin les descriptions des pages via la propriété prise en charge par `PageHeader` ;
- conserver les couleurs secondaires uniquement lorsqu'elles portent une information ;
- calmer la carte de synthèse enseignant sans retirer aucune donnée ou action ;
- préserver le comportement responsive et les améliorations d'accessibilité de HEDS25-636.

## Validation

1. test de contrat sur les six écrans et le socle partagé ;
2. suite de tests SI existante ;
3. build de production ;
4. contrôle navigateur desktop et mobile des six routes sur `test.hedsvs.ch` ;
5. aucune publication sur la production réelle.
