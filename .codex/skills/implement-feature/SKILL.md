# Implement feature

Use only with an issue and plan. Fail closed if plan missing, `validated` is not `yes`, branch is main/detached, or scope conflicts. Read inputs, work one task at a time, add tests, run checks after meaningful changes, update checkboxes, inspect final diff, and report exact evidence/risks. Preserve architecture/tenant isolation; do not improvise deviations, weaken security, upgrade unrelated dependencies, deploy, merge, or clean unrelated code. Output scoped code/tests/docs and updated plan. Validate acceptance criteria plus required lint/typecheck/tests/build. Stop for destructive work, secret/production access, security conflict, or exceeded scope.
