Ce guide décrit le processus de gestion côté Soins-infirmiers (SI).

## 1) Pré-requis

- Rôles/permissions SI configurés
- Variables `.env` valides (Firebase/Supabase)

## 2) Administration

- `Dashboard` — suivi global
- `Users` — gestion des comptes et droits
- `Institutions & Places` — référentiel des lieux SI
- `Votations` — processus décisionnels si utilisé
- `Validation & Réception` — workflows d’acceptation
- `Scroll policy` — règles d’UX si pertinent

## 3) Vérifications

- Les données s’affichent dans les vues SI
- Les workflows reflètent les états attendus

## 4) Bonnes pratiques

- Tenir un référentiel clair et à jour
- Historiser les changements importants
- Vérifier régulièrement les permissions
