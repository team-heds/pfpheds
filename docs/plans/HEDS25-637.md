# HEDS25-637 — Tests métier et permissions SI

## Périmètre

Cette story ajoute uniquement des tests et des fixtures de test. Elle ne modifie pas le comportement de production.

## Correspondance avec les critères Jira

1. Matrice Admin / RMSoins / EnseignantSoins
   - matrice tabulaire des quatre surfaces SI ;
   - refus explicite pour EtudiantSoins et visiteur anonyme ;
   - conservation du passe-droit `super.all`.
2. RLS des votes
   - lecture et écriture du vote propre par un enseignant actif ;
   - refus des votes d'autrui, des comptes hors SI et des comptes désactivés ;
   - visibilité limitée au module pour RMSoins ;
   - visibilité globale administrateur ;
   - transaction intégralement annulée.
3. Règles métier
   - année académique partagée, changement d'année et récupération après erreur ;
   - charge par identité canonique, identité inconnue et identité ambiguë ;
   - indicateurs qualité, créneau complet, incomplet, vide et horaire invalide.
4. Smoke test
   - authentification admin sur `test.hedsvs.ch` ;
   - chargement read-only des écrans SI critiques ;
   - absence d'erreur JavaScript et de réponse serveur 5xx ;
   - refus d'accès anonyme à une route SI protégée.

## Hors périmètre

- aucune migration de schéma ;
- aucune modification des données de production ;
- aucune modification du comportement applicatif ;
- aucune ouverture de votation ou notification.
