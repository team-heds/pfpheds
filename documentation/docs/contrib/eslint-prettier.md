title: ESLint et Prettier
---

## Commandes

```bash
npm run lint
npm run format
```

## Usage

- `lint` pour les controles de code
- `format` pour normaliser le style sur `src/`

## Limite actuelle

Le formatage ne couvre pas encore toute la base de code ni la documentation. Il faut donc garder une vigilance manuelle sur les nouveaux fichiers docs.
