# HEDS25-635 — Administration SI responsive mobile et iPad

## Objectif

Rendre les écrans d’administration Soins infirmiers utilisables au tactile sur mobile et iPad, sans modifier les règles métier ni la charte existante.

## Périmètre

- navigation admin sous forme de tiroir sur les écrans étroits ;
- dashboard Secrétariat SI ;
- dashboard RM SI ;
- dashboard Enseignant SI ;
- planning journalier ;
- feuille de charges ;
- cours en postulation ;
- en-têtes communs des pages admin.

## Règles d’adaptation

- cible mobile : 320–767 px ;
- cible tablette : 768–1024 px, portrait et paysage ;
- zones tactiles d’au moins 44 px ;
- filtres et actions principales en pleine largeur sur mobile ;
- tableaux conservés sans perte de colonnes, avec défilement horizontal explicite ;
- calendriers transformés en flux vertical ou carrousel horizontal selon leur densité ;
- aucune fonctionnalité masquée sur mobile ;
- fermeture automatique du tiroir après navigation.

## Validation

- tests unitaires SI existants ;
- build de production ;
- contrôle visuel desktop, iPad et mobile sur `test.hedsvs.ch` ;
- vérification de l’absence d’erreur console et de débordement global ;
- production exclue de ce ticket tant que la validation humaine n’est pas donnée.
