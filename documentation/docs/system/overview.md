## Vue d'ensemble

La plateforme regroupe plusieurs domaines fonctionnels dans une seule base de code.

## Domaines principaux

- administration et académique
- formation pratique
- planning et soins
- social et gamification
- applications intégrées

## Point de reprise

Quand on reprend le projet, il faut toujours raisonner en trois couches :

1. interface et navigation
2. services et logique métier
3. source de données réelle
