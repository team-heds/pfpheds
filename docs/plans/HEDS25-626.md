# HEDS25-626 — Journaliser les événements XP refusés

**État :** terminé sur `test.hedsvs.ch`, production inchangée.

## Objectif

Rendre les refus du moteur de gamification mesurables sans exposer les étudiants ni permettre une attribution manuelle de points.

## Périmètre

- journal privé et append-only des refus ;
- motifs contrôlés : règle absente, action non vérifiée, doublon, plafond et refus interne ;
- aucune donnée source, contenu de publication ou métadonnée libre conservée ;
- compteur sur 30 jours et ventilation par motif dans la console admin ;
- accès étudiant interdit au journal ;
- conservation du moteur XP autoritaire et de ses plafonds.

## Validation

- test SQL étudiant/admin et lecture privée interdite ;
- aucun XP attribué lors d’un refus ;
- agrégats sans donnée personnelle ;
- tests frontend du nouveau contrat ;
- déploiement et parcours navigateur exclusivement sur l’environnement de test.

## Preuves — 23 septembre 2026

- isolation SQL et droits privés validés ;
- refus hors liste blanche et système fermé validés sans attribution d'XP ;
- agrégats de la console accessibles à l'administrateur, sans donnée
  personnelle ;
- parcours navigateur admin et étudiant sans réponse HTTP en erreur ni
  connexion interdite ;
- test de contrôle du déploiement progressif :
  `gamification_rollout_controls_ok`.
