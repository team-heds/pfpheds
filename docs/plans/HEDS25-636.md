# HEDS25-636 — Accessibilité clavier des écrans SI

## Objectif

Permettre de parcourir et d’utiliser les écrans d’administration Soins infirmiers sans souris, avec des noms accessibles et un focus visible.

## Périmètre

- navigation admin et menu mobile ;
- dashboard Secrétariat SI ;
- dashboard RM SI ;
- dashboard Enseignant SI ;
- planning journalier ;
- feuille de charges ;
- cours en postulation.

## Critères

- les navigations utilisent des liens natifs ;
- les actions utilisent des boutons natifs ;
- tous les boutons à icône possèdent un nom accessible ;
- les filtres ont un label explicitement relié au champ ;
- `Échap` ferme le tiroir mobile et rend le focus à son déclencheur ;
- le menu replié reste utilisable au clavier ;
- le changement de route déplace le focus vers le titre de la nouvelle page ;
- les focus sont visibles et compatibles avec les couleurs forcées ;
- aucun `tabindex` positif.

## Validation

- parcours `Tab`, `Shift+Tab`, `Entrée`, `Espace` et `Échap` ;
- inspection des noms accessibles ;
- contrôle axe automatisé sur desktop et mobile ;
- tests SI existants et build complet ;
- publication uniquement sur `test.hedsvs.ch`.
