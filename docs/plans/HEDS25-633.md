# HEDS25-633 — Fiabiliser les postulations SI

## Objectif

Rendre cohérentes les listes de postulation des enseignants et des RM, sans modifier les données métier ni la production.

## Périmètre livré

- charger tous les créneaux avec pagination explicite ;
- limiter la liste à l'année académique active ;
- partager une seule détection des postulations entre les vues Enseignant et RM ;
- afficher le titre réel du cours et le jour provenant de `planning_time_slots.day` ;
- normaliser les espaces, tabulations et retours à la ligne dans les libellés ;
- conserver un lien direct au cours quand il existe ;
- déduire un lien manquant uniquement lorsqu'un seul cours vérifié existe pour le module ;
- signaler les liens manquants ou ambigus au lieu de choisir arbitrairement ;
- préserver le vote enseignant et l'assignation RM existants.

## Hors périmètre

- aucune correction automatique de données ;
- aucune migration de schéma ;
- aucun changement en production ;
- aucune transition Jira avant validation humaine.

## Validation attendue sur test

1. La liste affiche les créneaux de l'année active uniquement.
2. Les titres de cours sont lisibles et les jours ne sont plus vides.
3. Un enseignant SI peut voter et retirer son vote.
4. Un RM voit uniquement les postulations de ses modules et peut assigner un votant.
5. Les indicateurs `Lié`, `Lien unique déduit` et `À vérifier` correspondent à la qualité du lien au cours.
