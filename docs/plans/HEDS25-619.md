# HEDS25-619 — Aligner défis et badges sur le catalogue d’actions

Recherche : `docs/research/HEDS25-619.md`.

## Périmètre

Corriger uniquement les défis et badges de la copie Supabase de test. Les
actions autorisées restent `LOGIN`, `PROFILE_UPDATE` et `POST`, reliées à
`daily_login`, `update_profile` et `create_post`. Aucun nouvel événement métier,
aucune reprise rétroactive, aucune notification et aucune production.

## Plan ordonné

### 1. Formaliser et diagnostiquer le contrat des conditions

- [x] Ajouter une fonction privée qui valide et normalise les conditions de
  badges supportées (`total_xp`, `level`, `action_count`) et une RPC admin de
  diagnostic agrégé, sans donnée personnelle ni écriture.
- Fichiers attendus : nouvelle migration créée avec `supabase migration new`,
  nouveau test SQL `supabase/tests/gamification_badges_challenges_isolation.sql`.
- Autorisé : fonctions dans `gamification_private`, RPC admin en lecture seule,
  contraintes compatibles avec les lignes existantes. Interdit : exposer la
  table privée, accepter une action inconnue ou modifier les attributions.
- Tests : conditions valides/imbriquées/inconnues, droits admin/étudiant/anon,
  `search_path`, privilèges `PUBLIC` et résultat agrégé.
- Validation : exécuter le test dans une transaction annulée via Portly.
- Retour arrière : révoquer la RPC et remplacer les fonctions par une migration

- Validation : sauvegarde puis simulation et application sur `staging`
  seulement.
- Retour arrière : restauration des conditions originales depuis l'audit par
  migration compensatoire ; ne jamais supprimer les badges historiques.

### 3. Rendre l'attribution de badge et son bonus strictement idempotents

  lieu. L'utiliser dans les deux branches du moteur.
- Fichier attendu : même migration et tests SQL.
- Autorisé : remplacer la version active de
  `record_my_gamification_action` en conservant sa signature et ses droits.

  `legacy_unclassified`, identité fournie par le navigateur, écriture partielle.

### 4. Remplacer l'administration Firebase des badges
